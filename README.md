# XrayUtils — выбор конфигурации из подписок для Xray

XrayUtils — небольшая консольная утилита для Linux, которая помогает работать с URL-подписками Xray. Она загружает профили из подписок, показывает их в интерактивном меню и экспортирует выбранную конфигурацию в установленный Xray.

Проект подходит тем, кто хранит несколько серверов или подписок и хочет быстро переключаться между профилями без ручного копирования JSON-файлов.

## Возможности

- добавление нескольких URL-подписок;
- обновление подписок и выбор нужного профиля;
- удаление подписок с подтверждением;
- импорт локальной JSON-подписки;
- экспорт выбранного профиля и доступных GeoIP/GeoSite-данных для Xray;
- сохранение списка подписок между запусками.

## Преимущества

- **Простая задача и понятный интерфейс.** Утилита запускается в терминале и не требует отдельной панели управления.
- **Быстрое переключение.** Нужный профиль выбирается из меню, без ручного редактирования конфигурации.
- **Минимальный размер.** Проект решает одну задачу и не включает лишние функции полноценного клиента.
- **Локальный контроль.** Конфигурация выбирается и экспортируется на вашем Linux-компьютере.
- **Поддержка routing-ресурсов.** Если подписка их предоставляет, GeoIP и GeoSite загружаются вместе с профилем.

## Недостатки и ограничения

- **Только Linux.** Проект рассчитан на Linux и системные пути установки Xray.
- **Нет графического интерфейса.** Управление выполняется в терминале.
- **Перезапуск службы выполняется отдельно.** Основная программа не управляет службой Xray; для запуска программы с последующим перезапуском службы используйте `run.sh`.
- **Ограниченный контроль конфигурации.** Утилита выбирает профиль из подписки и применяет базовые параметры подключения; полноценного редактора конфигураций нет.
- **Нужен доступ к источнику подписки.** Для удалённых подписок требуется интернет и рабочий URL.
- **Без встроенной проверки доверия.** Добавляйте только подписки и локальные файлы из источников, которым доверяете.

## Установка и запуск

Сначала установите Xray-core официальным способом:

- [Репозиторий Xray-core](https://github.com/xtls/xray-core)
- [Официальный установщик Xray](https://github.com/XTLS/Xray-install)

```bash
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install
```

Затем из корня репозитория создайте окружение, установите зависимости и запустите программу:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```

Технические пути, формат хранения данных и настройки экспорта описаны в [TECHNICAL.md](TECHNICAL.md).

Для запуска XrayUtils с последующим перезапуском службы используйте скрипт из корня проекта:

```bash
./run.sh
```

## Как пользоваться

1. Запустите программу.
2. Выберите добавление подписки и вставьте её URL.
3. Откройте подписку и при необходимости обновите данные.
4. Выберите нужный профиль для экспорта в Xray.
5. Перезапустите или перечитайте конфигурацию Xray средствами вашей системы.

## Кому подойдёт

XrayUtils подойдёт пользователям Linux, которые:

- уже используют Xray-core;
- получают конфигурации через одну или несколько подписок;
- предпочитают терминал веб-панели;
- хотят держать инструмент выбора профилей отдельно от самого Xray.

Если нужен готовый графический клиент, автоматическое управление службой или сложная настройка маршрутизации, стоит выбрать более функциональное решение.
