# XrayUtils

Консольная утилита для управления URL-подписками и подготовки конфигурации для Xray. Программа загружает конфиги из подписок, позволяет выбрать один из них и записывает его в файл конфигурации Xray. При наличии routing-ресурсов подписки также сохраняет файлы GeoIP и GeoSite.

## Требования

- Python 3.11 или новее
- Доступ к интернету для загрузки удалённых подписок
- Права на запись в каталог данных проекта и, при экспорте, в системные каталоги Xray

## Установка и запуск

Из корня репозитория выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/main.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.

## Использование

В меню можно добавить подписку, выбрать сохранённую подписку, обновить её или удалить. Внутри подписки выберите конфиг, чтобы экспортировать его для Xray. Перед удалением программа попросит ввести `DELETE`.

Подписки загружаются по HTTP(S). Также можно добавить локальный JSON-файл, указав URL вида `file:///полный/путь/к/config.json`. Локальный файл может содержать один объект конфигурации или список конфигураций.

При экспорте выбранный конфиг записывается в `/usr/local/etc/xray/config.json`; поле `inbounds` заменяется значением из `src/constants.py`. Если подписка содержит GeoIP или GeoSite, данные сохраняются в `/usr/local/share/xray/geoip.dat` и `/usr/local/share/xray/geosite.dat` соответственно. Утилита не устанавливает Xray и не перезапускает его службу.

## Данные и настройки

- Состояние подписок хранится в `data/subs.pkl`.
- `data/urls.json` используется как резервный список URL, если сохранённое состояние не удалось загрузить.
- HTTP-заголовки подписки, пути экспорта и настройки `inbounds` заданы в `src/constants.py`.

Для изменения путей Xray или параметров `inbounds` отредактируйте `src/constants.py` перед запуском.

## Зависимости

Сторонние зависимости перечислены в `requirements.txt`: `requests` используется для загрузки подписок, `questionary` — для интерактивного меню. Остальное использует стандартную библиотеку Python.

> `data/subs.pkl` — локальный файл сериализации Python. Не загружайте и не используйте файл из недоверенного источника.
