# Техническая информация

Этот документ содержит сведения для разработчиков и пользователей, которым нужно изменить поведение проекта. Основной обзор и инструкции для обычного запуска находятся в [README.md](README.md).

## Требования

- Linux;
- Python 3.11 или новее;
- доступ к интернету для загрузки удалённых подписок;
- права на запись в каталог данных проекта и системные каталоги Xray при экспорте.

## Файлы и каталоги

- `data/subs.pkl` — сохранённое состояние подписок в формате сериализации Python;
- `data/urls.json` — резервный список URL, используемый при невозможности загрузить `subs.pkl`;
- `src/constants.py` — HTTP-заголовки, пути экспорта и значение `inbounds`;
- `requirements.txt` — версии внешних Python-зависимостей.

Не загружайте `data/subs.pkl` и другие сериализованные файлы из недоверенных источников.

## Экспорт

При выборе профиля программа записывает конфигурацию в:

- `/usr/local/etc/xray/config.json`;
- `/usr/local/share/xray/geoip.dat`, если подписка содержит GeoIP;
- `/usr/local/share/xray/geosite.dat`, если подписка содержит GeoSite.

Перед экспортом поле `inbounds` заменяется значением `INBOUNDS` из `src/constants.py`. Для изменения путей или локальных входящих подключений отредактируйте этот файл.

Утилита не устанавливает Xray, не проверяет конфигурацию командой Xray и не перезапускает его службу.

## Поддерживаемые источники

Удалённые подписки загружаются по HTTP(S). Локальный JSON-файл добавляется через URL `file:///...` и может содержать один объект конфигурации или список объектов.

Для HTTP-подписок поддерживаются ETag, резервный URL и routing-заголовок с адресами GeoIP/GeoSite, если они предоставляются источником.

## Зависимости

- `requests` — загрузка HTTP(S)-подписок;
- `questionary` — интерактивное меню;
- остальные пакеты из `requirements.txt` — зависимости этих библиотек.
